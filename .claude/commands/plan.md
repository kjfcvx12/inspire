## 2. 데이터셋 판단
**데이터가 필요한 주제인 경우 (예측 모델, RAG용 문서 등)**
- WebSearch로 후보를 찾는다: Kaggle, Hugging Face Datasets, UCI, 공공데이터포털(data.go.kr), AI Hub, 서울열린데이터광장 등.
- 라이선스와 크기, 컬럼/타깃이 주제에 맞는 상위 1개를 고르고 대안 2개를 한 줄씩 적는다.
- 직접 다운로드가 가능하면(curl/WebFetch) `data/`에 저장하고, 행·컬럼 수와 타깃 후보를 요약한다.
- 다운로드가 막히면 다운로드 링크와 필요한 컬럼만 알려주고, 즉시 쓸 수 있는 합성 샘플 데이터(`data/sample.csv`)를 생성해 진행한다.
- 시간 제한: 데이터 탐색은 최대 10분.

**데이터가 필수가 아닌 주제인 경우 (LLM 에이전트, 도구 연동 등)**
- 구현 아이디어 5개를 제안한다. 각 항목은 `제목 — 한 줄 설명 — 난이도(하/중/상) — 2시간 내 가능 여부`로 쓰고, 마지막에 추천 1개와 이유를 적는다.
