# 120분 시간표
분석 10 · 설계 10 · 구현 65 · 검증 10 · 발표 준비 15 · 여유 10

| 누적 분 | 단계 | 기준 |
|---|---|---|
| 0~10 | 분석 | `/plan`, START 시각을 `docs/decisions.md`에 기록 |
| 10~20 | 설계 | `/harness`로 검사·골든 케이스 준비 |
| 20~85 | 구현 | `/build-loop`로 반복, 20분마다 `/checkpoint`, 수시로 `/timecheck` |
| 85 | **기능 동결** | 이후 코드 변경은 버그 수정만 |
| 85~95 | 검증 | `verifier` 에이전트, `/demo-ready` |
| 95~110 | 발표 준비 | `/present`, `interviewer` 에이전트 |
| 110~120 | 여유 | 리허설, 데모 실패 대비 확인 (100분 이후 새 기능 금지) |

- 구현은 핵심 기능 end-to-end 먼저, 확장은 그다음
- 검증: 샘플 입력 테스트 1~2개 + 엣지 케이스 + 간단한 지표
