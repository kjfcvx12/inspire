1. `python scripts/check.py`(키가 있으면 `--api`) 2. 앱이 처음부터 실행되는지 3. 샘플 데이터 정상 흐름 4. README 실행법 5. `.env` 값 커밋 여부 6. API 실패 시 mock 폴백 7. 발표 대본과 실제 동작 일치 및 3분 안에 읽히는지(글자 수·낭독 시간으로 확인).
문제가 있으면 수정하고 결과를 요약한다. 독립 확인이 필요하면 `verifier` 에이전트를 쓴다.

## 출력 형식 (고정)
항목 7개를 `✅/❌ 항목 — 근거(실행 명령·결과)` 한 줄씩. ❌는 수정 후 재확인한 결과를 덧붙인다.

## 검증
점검은 실제 실행으로 한다(읽기만으로 ✅ 금지). 한 항목씩 순서대로 진행한다.
