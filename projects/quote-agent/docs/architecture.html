견적 에이전트는 이렇게 만들어졌습니다

대학이 "3개월에 5명으로 해주세요"처럼 문장으로 요청하면, 기준안과 비교한 견적서를 만들어 보여주는 웹 서비스입니다. 서울대 연구행정시스템 용역을 기준안으로 씁니다.

AI가 일하고, 코드가 확정합니다

판단과 문장은 AI 에이전트가 맡고, 금액은 틀리면 곧바로 손해라서 계산 엔진이 확정합니다. AI의 제안과 설명은 모두 코드와 다른 AI가 한 번 더 확인합니다.

일AI 에이전트가 하는 것코드가 확정하는 것
요청 이해문장에서 대학·기간·인원·범위를 뽑는다. 정보가 모자라면 한 번 되묻는다. 의뢰서 문서에서도 뽑는다.값 범위와 충돌을 검사한다. 틀리면 AI에게 오류를 돌려준다.
가정값 추정표에 없는 대학의 규모 계수와 신규 항목의 공수 비율을 근거와 함께 제안한다. 과거 견적을 참고한다.허용 범위로 자르고 견적에 'AI 추정'을 남긴다. 표에 있는 값은 AI가 덮어쓸 수 없다.
금액 계산계산 도구를 불러 시나리오를 만든다. 다른 AI 하나가 규칙만 보고 독립적으로 다시 계산한다.모든 금액은 엔진이 정한다. AI 계산이 다르면 항목별로 나란히 보고 규칙을 다시 읽혀 판정하지만, 금액은 엔진 값 그대로다.
설명 작성결과를 문장으로 쓴다. 검증에서 문제가 나오면 최대 2번 다시 쓴다.문장 속 금액이 계산 결과에 없으면 '미검증'으로 표시한다. 다른 AI가 사실과 모순되는지 판정한다.

이렇게 나눈 이유: AI 비중을 키울수록 판단은 좋아지지만 시간·비용이 늘고 같은 입력에 같은 답이 나온다는 보장이 사라집니다. 그래서 숫자만은 코드에 두었습니다.

구조도

예시 한 건을 따라가 보면

"한양대가 4개월에 5명으로 요청해. 데이터 이관 계획도 넣어줘"
  1. 입력 화면
    폼에 문장을 넣고 '견적 만들기'를 누릅니다. 의뢰서 파일을 올렸다면 읽은 내용이 입력창에 먼저 채워집니다.
  2. 계획 AI
    (켠 경우) 요청 그대로의 안과 비교할 안을 정리해 에이전트에게 넘깁니다.
  3. 규모 계수 추정 AI 코드
    한양대는 가정값 표에 없습니다. AI가 계수를 근거와 함께 제안하고(예: 0.7, 확신 낮음), 코드가 범위를 확인해 견적 경고에 'AI 추정'을 남깁니다.
  4. 신규 항목 공수 추정 AI
    '데이터 이관 계획'이 기준 설계 전체의 몇 %인지 기존 단계에 빗대어 제안합니다(예: 8%).
  5. 과거 견적 검색 코드
    이력에서 같은 대학과 비슷한 조건의 견적을 찾아 위 추정에 참고로 줍니다. 과거 금액은 쓰지 않고 건수와 수주 여부만 봅니다.
  6. 계산 코드
    엔진이 인원·기간·추정값으로 금액을 계산하고 기준안과 항목별로 비교합니다.
  7. 설명 작성 AI
    기준안과 어디가 얼마 다른지 문장으로 씁니다. 'AI 추정'인 값은 그렇다고 밝힙니다.
  8. 검증과 다시 쓰기 검증
    문장 속 금액이 계산 결과에 없거나 AI 검증이 모순을 찾으면 에이전트가 설명을 다시 씁니다(최대 2번).
  9. AI 교차검증 AI
    다른 AI가 규칙만 보고 합계를 다시 계산해 엔진과 비교합니다. 다르면 어느 쪽이 규칙에 맞는지 판정하되, 화면 금액은 엔진 값입니다.
  10. 표시·저장 화면
    금액 → 'AI 추정' 경고 → 설명 → 검증 결과 순으로 보여 주고, 이력에 저장하고, 엑셀로 내려받을 수 있습니다.

표에 있는 대학(예: 고려대)이면 3~5번을 건너뜁니다. 대학·기간·인원이 모두 없는 "견적 좀 보여줘"는 계산하지 않고 한 문장으로 되묻습니다.

죽지 않게 만든 장치

  • API가 안 될 때 규칙 기반 대체 모드로 계속 동작합니다. 화면에 mock이라고 표시하고 정확도는 낮습니다.
  • 추정이 실패하면 규모 계수는 1.0 가정과 경고로, 공수는 에이전트가 직접 추정하는 기존 방식으로 돌아갑니다.
  • 검증기가 응답하지 않으면 문제로 보지 않고 결과를 그대로 냅니다. 검증이 결과를 막지 않습니다.
  • 횟수 한도: 도구 반복 8번, 설명 다시 쓰기 2번, 되묻기 1번.
  • 테스트 171개와 정답 예시 18+18건으로 숫자를 다시 확인합니다.

외부로 나가는 것

  • 사이드바에서 'AI 해석'을 끄면 아무것도 나가지 않고 규칙 기반으로만 동작합니다.
  • 요청 문장은 AI 해석을 켤 때만 나갑니다.
  • 'AI 교차검증'을 켜면 단가와 계산 규칙도 AI로 전송됩니다. 따로 끌 수 있습니다.
  • 의뢰서를 올리면 문서의 앞 12,000자가 AI로 전송됩니다. 문서 안의 지시문은 따르지 않고 요구사항만 뽑으며, 결과는 입력창에만 채워지고 자동 실행되지 않습니다.
  • API 키는 .env에만 두고 커밋하지 않습니다.

에이전트 프레임워크(LangChain 등)는 쓰지 않고 도구 호출 반복을 직접 작성했습니다. 동작을 설명하고 반복 횟수를 직접 통제하기 위해서입니다.

화면 도구 선택과 전환 경로: Streamlit과 pandas는 2시간 안에 동작하는 데모를 만들기 위한 선택입니다. pandas는 app.py의 표 표시·편집에만 쓰이고 견적 계산(quote/engine.py)은 쓰지 않습니다. 서비스로 키울 때는 계산 엔진과 에이전트를 FastAPI로 분리하고 화면을 별도 프론트엔드(React 등)로 바꿉니다. 엔진·에이전트가 화면과 이미 분리되어 있어 화면만 교체하면 됩니다.
