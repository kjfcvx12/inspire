견적 에이전트 구조

견적 에이전트는 이렇게 만들어졌습니다

대학이 "3개월에 5명으로 해주세요"처럼 문장으로 요청하면, 기준안과 비교한 견적서를 만들어 보여주는 웹 서비스입니다. 서울대 연구행정시스템 용역을 기준안으로 씁니다.

핵심은 역할을 셋으로 나눈 것

AI는 말을 알아듣는 일만 하고, 금액은 파이썬 코드가 계산하고, 설명에 적힌 금액은 검증 코드가 다시 맞춰 봅니다. AI가 금액을 틀리게 써도 화면에서 '미검증'으로 드러나게 하려는 구조입니다.

AI (Claude)요청 문장을 읽고 어떤 조건인지 정리, 결과를 설명
계산 코드 (파이썬)공수·원가·이익·부가세까지 모든 금액을 계산. 같은 입력이면 항상 같은 답
검증 코드AI가 쓴 설명 속 금액이 계산 결과에 있는지 대조

구조도 (위에서 아래로 흐릅니다)

1. 화면

app.py

입력창, 결과 탭(요약·견적서·비교·근거·조건 수정·이력, 기록 탭은 미검증 금액이나 mock일 때만), 가정값 편집, 엑셀 내려받기.

Streamlit 1.65pandas 3.0
요청 문장 ↓  ·  결과 ↑

2. 에이전트

quote/agent.py

AI에게 문장과 도구 4개(기준안 조회 · 견적 계산 · 팀 다시 짜기 · 예산에 맞추기)를 주고, AI가 도구를 부르면 결과를 돌려주는 일을 최대 8번 반복합니다.

Anthropic SDK 1.13모델 claude-sonnet-5-5
AI가 고른 조건 ↓ (형식이 틀리면 거부)  ·  계산 결과 ↑

3. 계산·검증 (AI 없음)

quote/

모든 금액이 여기서 정해집니다. 숫자는 테스트로 다시 확인할 수 있습니다.

engine.py견적 계산, 팀 재설계, 예산 맞추기, 민감도
verify.py설명 속 금액을 계산 결과와 대조
assumptions.py단가·비중을 JSON 파일에서 읽기
export.py엑셀 견적서 만들기
pydantic 2.14openpyxl 3.1

AI 호출 창구

common/llm.py

AI 호출은 모두 여기를 지납니다. 일시 오류는 기다렸다가 최대 3번까지 시도하고, 끝내 실패하면 규칙 기반 대체 모드로 넘어갑니다.

tenacity 9.2python-dotenv 1.2
견적·이력·가정값 읽고 쓰기 ↓  ·  API 호출 →

4. 저장 (파일만, 서버 없음)

data/assumptions.json 단가·비중 가정값  ·  data/quotes.db 견적 이력(SQLite)  ·  data/demo_cache.json 시연 저장본  ·  logs/usage.jsonl API 사용량

외부

Anthropic API. 키는 .env에만 두고 커밋하지 않습니다.

예시 한 건을 따라가 보면

"고려대가 3개월에 5명으로 요청하면 견적이 얼마나 달라져?"
  1. 입력화면
    폼에 문장을 넣고 '견적 만들기'를 누릅니다. 입력만 바꿔서는 다시 실행되지 않도록 폼으로 묶어 두었습니다.
  2. 조건 정리AI
    "고려대", "3개월", "5명"을 뽑아 calculate_quote 도구를 부릅니다. '고대' 같은 줄임말은 고려대학교로 바꿔 줍니다.
  3. 형식 검사코드
    pydantic이 값 범위와 충돌(예: 주 수와 개월 수가 다름)을 검사합니다. 틀리면 AI에게 오류를 돌려주어 다시 시도시킵니다.
  4. 계산코드
    고려대 규모 계수(가정값 0.8)와 인원·기간으로 금액을 계산하고, 기준안과 항목별로 비교합니다.
  5. 설명 작성AI
    계산 결과를 받아 "기준안보다 어디가 얼마 달라졌는지" 문장으로 씁니다.
  6. 금액 대조검증
    문장 속 금액이 계산 결과에 없으면 화면에 '미검증'으로 표시합니다.
  7. 표시·저장화면
    탭에 결과를 그리고, 이력(SQLite)에 저장하고, 사용량을 기록합니다. 원하면 엑셀로 내려받습니다.

에이전트 프레임워크(LangChain 등)는 쓰지 않고 도구 호출 반복을 직접 작성했습니다. 동작을 설명하고 반복 횟수를 직접 통제하기 위해서입니다.

죽지 않게 만든 장치

  • API가 안 될 때 규칙 기반 대체 모드로 계속 동작합니다. 화면에 mock이라고 표시하고, 정확도는 낮습니다.
  • 민감한 건은 사이드바에서 'AI 해석'을 끄면 요청 문장이 외부로 나가지 않습니다.
  • 반복 한도 8번. 넘으면 계산된 범위까지만 보여줍니다.
  • 테스트 136개와 정답 예시 18+18건으로 숫자를 다시 확인할 수 있습니다.

알려진 한계

  • 실제 고객의 견적서 형식을 아직 모릅니다. 가정값 파일만 바꾸면 되도록 만들어 두었습니다.
  • 단가·기준안은 공개 정보가 없어 모두 가정값이고, 견적은 담당자 검토 전 초안입니다.
  • AI 정답 예시 통과율은 실행마다 조금 달라질 수 있습니다(같은 날 17/18~18/18).
