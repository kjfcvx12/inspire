# 리허설 결과 (2026-10-14)

> 더미 주제로 키트의 전체 흐름(계획 → 하네스 → 구현 → 검증 → 발표)을 처음부터 끝까지 한 번 돌린 기록.
> 실행 위치: 키트를 임시 폴더로 복사해서 진행(원본 저장소는 건드리지 않음). 산출물은 임시 폴더에만 있고, 얻은 교훈만 원본 키트에 반영했다.

## 주제와 결과물
- 주제: 유방암 진단 보조 분류(sklearn 내장 Wisconsin 데이터 569행×30특징, API 호출 없음)
- 결과물: 로지스틱 회귀 서빙 모델, 입력 검증, Streamlit 데모, 골든·데모 테스트 22개, CV 근거 스크립트, 발표 문서(대본 약 650자)
- 최종 하네스: 3 PASS / 1 WARN(API 키 없음) / 0 FAIL, 변이 테스트(확률 열 반전)에서 테스트가 실제로 FAIL

## 소요 시간 (주의)
- 시작부터 최종 커밋까지 약 7분(AI가 실행한 벽시계 시간). **사람이 직접 하는 시간이 아니므로 120분 계획의 근거로 쓸 수 없다.**
- 이 리허설이 보여 주는 것은 소요 시간이 아니라 **키트의 마찰과 실패 유형**이다. 사람의 시간 측정은 직접 한 번 돌려 봐야 한다.

## 효과가 있었던 것
| 항목 | 결과 |
|---|---|
| 골든 테스트를 구현 전에 작성 | 구현 전 하네스가 FAIL → 구현 후 PASS로 완료 기준이 명확했음 |
| `verifier` 에이전트 (약 1분) | 비정상 값(1e12, -50, 전부 0)이 조용히 예측되는 **실제 결함**을 찾음 |
| `interviewer` 에이전트 (약 1.5분) | 발표 수치의 근거 코드 부재, 타입만 보는 약한 테스트, 학습 표본 혼입 데모, "0원" 표현 오류를 지적 |
| CV 재검증 | 단일 홀드아웃으로 내린 "임계값 조정 불필요" 결정이 **틀렸음**을 확인(재현율 0.958→0.972) |

## 발견한 문제와 조치
| # | 문제 | 조치 |
|---|---|---|
| 1 | 발표 수치(CV, 임계값 스윕)가 일회성 명령 결과라 재현 불가 | `scripts/`에 증거 스크립트로 남기고 `docs/evidence.md`에 저장하도록 규칙화 (`/build-loop`, `/present`, `CLAUDE.md`) |
| 2 | 테스트가 타입·범위만 확인해 틀린 모델을 못 잡음 | 방향 단언, 변이 테스트, 극단값 엣지를 `/harness`에 규칙화 |
| 3 | 비정상 입력이 조용히 통과 | `verifier` 지침에 "조용히 의미 없는 결과" 점검 추가 |
| 4 | 작은 홀드아웃 하나로 결정을 내림 | CV 재확인 + 결정 번복을 `decisions.md`에 남기는 규칙 (`/build-loop`) |
| 5 | "기록 없음"을 "0원"으로 발표 | `/present`: 측정 없음 ≠ 0원, 런타임 비용과 개발 비용 구분 |
| 6 | 결정 로그 시각을 임의로 적음 (내가 틀림) | 실제 시각으로 정정, "시각은 추측 금지" 규칙 + `scripts/start.py` |
| 7 | PowerShell(한글 로케일)에서 시각 포맷이 `01시 12`로 나오고 `Get-Content`/`Set-Content`로 한글이 깨짐 | `scripts/start.py` 추가, `CLAUDE.md`에 "Edit/Write 도구나 파이썬으로만 수정" 규칙 |
| 8 | `check.py`가 pytest 실패 시 마지막 줄만 보여 원인을 알 수 없음 | FAILED/ERROR 줄을 표시하도록 수정 |
| 9 | 키트를 복사하는 과정에서 프로젝트의 `.env`가 함께 복사됨 | 즉시 삭제, 내용은 읽지 않음, 커밋에는 포함되지 않음 |

## 한계 (이 리허설이 검증하지 못한 것)
- 스킬(`/plan` 등)을 슬래시 명령으로 호출하지 않고 문서 지침을 직접 따라 했다. 호출 자체의 동작은 미검증이다.
- 에이전트 두 개는 실제로 호출해 확인했다. 단, 둘 다 임시 폴더 기준이다.
- 실제 `streamlit run` 서버와 브라우저 렌더, API 호출, 비용 기록의 실호출은 확인하지 못했다.
- 주제가 RAG/에이전트·이미지인 경우의 마찰은 이 리허설에서 드러나지 않았다.
